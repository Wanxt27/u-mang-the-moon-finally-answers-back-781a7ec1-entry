A make.fun entry for [The Moon Finally Answers Back](https://make.fun/bounty/u-mang-the-moon-finally-answers-back-781a7ec1).

`main.ts` (Node 22, stdlib only) writes the Moon's one-line comeback — 105 characters — to `/output/entry.txt`:

> Four billion years of wishes, howls and 2 a.m. promises — and not one of you ever wished me good night.

Run it with:

```sh
node main.ts
```
